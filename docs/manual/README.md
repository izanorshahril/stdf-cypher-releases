# STDF Cypher manual

STDF Cypher reads STDF v4 test data and shows it in a desktop app, a local dashboard or a self-contained HTML report.
Everything runs on your PC and the app sends your data nowhere.

This manual is also in the app: press F1, click **?** in the banner, or open **Help** at the bottom of the side bar.

## Contents

1. [Getting started](01-getting-started.md): start the app, open files, try it without data.
2. [The window](02-layout.md): side bar, banner, side panel, status bar, search and menus.
3. [Files and datasets](03-files.md): the Files pane, groups, merging, renaming and closing.
4. [Pages](04-pages.md): what each page shows and how to use it.
5. [Part filter](05-filters.md): the filter language, with examples.
6. [Look and themes](06-look.md): themes, fonts, accent, effects, chart colours and shaded cells.
7. [Settings](07-settings.md): part identification, labels, die coordinates and the other shared settings.
8. [Command line](08-command-line.md): every command and its options.
9. [Troubleshooting](09-troubleshooting.md): common problems, where files are kept and how to report a bug.
